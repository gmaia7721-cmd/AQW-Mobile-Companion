# AQW Mobile Companion

Android companion for AdventureQuest Worlds focused on class advice, combat combos, Forge enhancements, and Ultra boss preparation.

## Main sections
- **Classes:** manually select the class in use; class-specific skill rotations and enhancement builds are being organized.
- **Ultras:** select a boss and consult role, party composition, mechanics, and consumable recommendations.
- **Forge:** compare weapon, helm, and cape enhancements by class and activity.
- **Library:** reference traditional enhancements, Forge traits, potions, elixirs, tonics, and scrolls.

The app is an advisory companion. It does not automate gameplay or read game memory.

## Build
GitHub Actions builds the Android APK and publishes it as a GitHub release. The installed app checks the latest release and offers to open its download page when a newer version is available.
