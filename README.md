# AQW Mobile Companion

Companion visual para Android 14 e Artix Experimental Launcher.

## Estado da versão 0.1
- Painel flutuante Android (permissão concedida pelo usuário).
- Interface inicial para acompanhar o mapa.
- Sem automação de combate, leitura de memória, injeção ou alteração do cliente AQW.

A identificação de monstros por imagem/OCR ainda não está implementada nesta versão.

## Compilar
O GitHub Actions executa `assembleDebug` e publica o APK como artefato de workflow.
